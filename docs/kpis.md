# في طريقي — تعريف المؤشرات (KPIs)

المصدر: business doc §17. التنفيذ: `backend/apps/adminpanel/kpis.py`، العرض: `GET /api/admin/kpis/?days=30&include_test=false`.

## التعريفات

- **الطلب المؤهل:** طلب أُنشئ داخل الفترة ولم يصدر من حساب تجريبي (`User.is_test_account`). يمكن تضمين التجريبي بـ `include_test=true`.
- **الطلب المحسوم:** مؤهل وحالته `CONFIRMED` أو `CANCELLED` أو منتهٍ (حالة `EXPIRED` أو `OPEN` تجاوز `expires_at`). الطلبات المفتوحة لا تدخل في مقام معدلات النتائج حتى لا تُخفض المعدل ظلمًا.
- كل نسبة تُرجع كسرًا بين 0 و1، أو `null` إن كان المقام صفرًا.

| المؤشر | الصيغة |
|---|---|
| الطلبات المنشورة | عدد الطلبات المؤهلة (ومعها عدد لكل يوم) |
| نسبة وصول سائق مهتم | طلبات لها اهتمام واحد على الأقل ÷ المؤهلة |
| معدل التأكيد | `CONFIRMED` ÷ المحسومة |
| نسبة الانتهاء دون تأكيد | المنتهية ÷ المحسومة |
| الإلغاء قبل التأكيد | `CANCELLED` (طلبات) ÷ المحسومة |
| الإلغاء بعد التأكيد | مشاوير `CANCELLED` ÷ كل المشاوير المنشأة في الفترة |
| زمن أول اهتمام | متوسط (أول اهتمام − إنشاء الطلب) بالثواني |
| زمن التأكيد | متوسط (`confirmed_at` − إنشاء الطلب) بالثواني |
| السائقون النشطون | سائقون حدّثوا موقعهم خلال آخر 24 ساعة |
| العملاء العائدون | عملاء لديهم طلبان أو أكثر ÷ العملاء ذوو طلب واحد على الأقل |

## تنبيهات

- لا يُحكم على نجاح المنتج بمؤشر واحد.
- «مكرر» غير معرّف آليًا بعد؛ يُعالج بوسم الحساب كتجريبي يدويًا من الإدارة (`is_test_account`).
